# 智慧农业物联网系统测试报告

## 更新日期：2026-08-10

---

## 1. 测试概述

### 1.1 测试目的

验证智慧农业物联网系统的以下功能：
- 硬件端与服务器端的通信可靠性
- 设备自动分类和区域划分功能
- 多种控制类型的执行正确性
- 指令执行的正确性和一致性
- WebSocket实时通信的有效性
- 回执确认和超时机制
- 控制卡片自动加载功能
- 摄像头模块集成（视频流、云台控制、颜色追踪、帧上传）
- 错误处理和异常情况的处理能力

### 1.2 测试环境

| 组件 | 规格 | 版本 |
|------|------|------|
| 硬件 | STM32F103C8T6开发板 | - |
| 摄像头节点 | 树莓派 5B + Picamera2 + PCA9685 云台 | - |
| WiFi模块 | ATK-MB026 | V1.1 |
| 服务器 | 本地开发服务器 | Next.js 16 |
| 数据库 | MySQL / SQLite | 8.0 / 3.x |
| 前端框架 | React + TypeScript | 18.x |
| WebSocket | 原生WebSocket | 8080端口 |
| 视频流服务 | 树莓派本地 MJPEG 流 | 8081端口 |
| 测试脚本 | Node.js | 18.0+ |
| 测试工具 | Postman / curl | - |

### 1.3 测试范围

本次测试涵盖以下核心功能模块：
1. 设备数据上报与自动分类
2. IP区域自动划分
3. 执行器多类型控制
4. WebSocket实时通信
5. 回执确认与超时机制
6. 控制卡片自动加载
7. 区域视图页面
8. 错误处理与异常恢复
9. 摄像头模块集成（v2.2.0 新增）
